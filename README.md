# procedural-horse-race

1. to create the game, i need to create a list of horses, tracks, and coins to have a base for this game, i can also use constants. the tracks are 15 chars long for each horse
2. i am using the following void functions: isWinner showing which horse won, turn for each coin flip for the horses, and printTrack
3. the program will show the progress of each horse for each turn until a horse completes its track, the coin flip determines whether a horse moves forward or not (choosing 1 or 0 at random).
4. the user will press a key to play/continue the game.
